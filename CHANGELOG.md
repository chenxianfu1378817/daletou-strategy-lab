# Changelog

## V1.1.0

- Removed frontend generation of official recommendation numbers.
- Added fail-closed saved Evidence for BET/SKIP decisions.
- Added Atomic Bet comparison across Single, Multiple, Hybrid and Smart.
- Added 1000-seed Random baselines and 100/300/500-period ablation reports.
- Established recommendation.json as the immutable production source of truth.

- 实现模型、覆盖优化、预算上限、Bet/Skip 与 Strategy Lab 基础设施。
